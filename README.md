# Archived-Pancake
A simple local server built with [Node.js](https://nodejs.org/pt-br) that allows you to send files from one device to another.

To acess the server from another device, is needed to execute the command _"ipconfig"_ on a **CMD** tab, and descover the IPv4 from your device.

so, you need a structure similar to this on your browser search tab: http://_(IPv4)_:_(Port Number, on the default case, 3030)_

You need to create a folder named "toIndex" inside the project folder and place the files there.
